## Workflow

1. Inspect the existing implementation.
2. Document incomplete features and known issues.
3. Choose one improvement at a time.
4. Implement, test, and document changes.
5. Update the project's status and next steps.

## Principles

- Keep every project in its own repository.
- Preserve the original CodePath work and credit its source.
- Improve projects incrementally rather than rewriting everything.
- Prioritize learning, maintainability, and demonstrable functionality.
